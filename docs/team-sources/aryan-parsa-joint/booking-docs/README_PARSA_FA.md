# پارسا — فایل آماده بخش Raumbuchung

این ZIP برای این ساخته شده که **علی آن را در پروژه مشترک LCC Campus Board ادغام کند**. لازم نیست تو فعلاً Git یا برنامه‌نویسی یاد بگیری.

## این کد چه کاری می‌کند؟

1. صفحه `Raum reservieren` با انتخاب اتاق، تاریخ، مدت و ساعت آزاد
2. ذخیره رزرو آزمایشی در همان دیتابیس SQLite پروژه علی
3. جلوگیری از رزرو روی کلاس یا رزرو دیگری که همان زمان را اشغال کرده
4. نمایش موفقیت، شماره رزرو و کد لغو
5. صفحه `Reservierung stornieren` برای لغو با شماره رزرو + کد
6. دکمه‌ها و متن‌های آلمانی و انگلیسی، سازگار با صفحه لمسی
7. مدیریت خطا و رسیدی که بعد از ۶۰ ثانیه محو می‌شود (پیشنهاد اولیه و نیازمند بررسی رضا)

## فقط چه کاری باید انجام دهی؟

ZIP را برای علی بفرست؛ علی باید `README_FOR_ALI.md` را بخواند. فایل `apply_to_repo.py` برای اتصال تغییرات به کدهای اوست. روی شاخه `main` اجرا نمی‌شود تا کد اصلی آسیب نبیند.

**هنوز روی GitHub علی نصب نشده است.** تست کامل Next.js فقط پس از ادغام و نصب وابستگی‌ها ممکن است. این کد از قوانین رزرو پیشنهادی B1 استفاده می‌کند، و علی/تو باید ساعت‌ها، مدت رزرو و نحوه رسید را تأیید کنید.

## مدرک HCI

برای Booklet خودت از `docs/PARSA_HCI_EVIDENCE_TEMPLATE.md` استفاده کن؛ مواردی مثل نقاشی اولیه، تاریخ تست، اسکرین‌شات و مشاهده کاربر باید **واقعی** باشند. من نتایج تست انسانی جعل نکرده‌ام.
