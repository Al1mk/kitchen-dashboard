# پارسا + آرین — نسخه هماهنگ با ZIP اصلی آرین

این بسته از `LCC_K1_COMPLETE_V12_2_QA_VERIFIED.zip` آرین ساخته شده، نه از نقشه جدید حدسی.

- نقشه‌های 1OG و 2OG و 3OG همان سه PNG اصلی ZIP آرین هستند؛ **دقیقاً با همان بایت‌ها**.
- همه ۴۷ رکورد اتاق در `rooms.json` آرین بدون تغییر حفظ شده‌اند.
- از ۲۱ اتاق انتخابی پارسا، ۲۰ اتاق دقیقاً در فایل آرین وجود دارند.
- `K1-114` در فایل آرین نیست؛ فقط از نقشه‌ای که پارسا جداگانه از دانشگاه فرستاده استفاده شده و روی نقشه تعاملی هیچ موقعیت ساختگی ندارد.
- برچسب «قابل رزرو» صرفاً فرضِ دمو است، نه تأیید دانشگاه. تعدادی از اتاق‌ها دفتر و آزمایشگاه هستند.
- قابلیت رزرو در مرورگر فقط شبیه‌سازی محلی است، نه رزرو واقعی و نه اتصال به SQLite.
- کد سرور SQLite برای علی در پوشه `02_FUER_ALI_NEXTJS/` قرار دارد؛ فقط بعد از تست ادغام در پروژه او قابل ارائه به‌عنوان نسخه گروهی است.

## فایل‌ها
- `01_NETLIFY_DEMO/`: محتوای سایتِ نمایشی برای Netlify Drop. `index.html` نقشه آرین و `booking/index.html` رزرو پارساست.
- `02_FUER_ALI_NEXTJS/`: کد و نصب‌کننده محافظت‌شده برای پروژه اصلی علی؛ ابتدا `README_FOR_ALI.md`.
- `ROOMS_SOURCE_AND_BOOKING.json`: نام/نوع/طبقه ۲۱ اتاق، برگرفته از کاتالوگ آرین و اضافه‌شدن K1-114 بدون مختصات.
- `ARYAN_ORIGINAL_ROOMS_47.json`: فایل اصلی آرین برای مقایسه و اعتبارسنجی.
- `PARSA_BOOKLET_AKTUALISIERUNG_DE.md`: متن آلمانی به‌روز برای قرار دادن در Booklet؛ دادهٔ تست انسانی ساخته نشده است.

## نکته
در فهرست پارسا `K1-103-K1-114` به معنی دو اتاق ۱۰۳ و ۱۱۴ تعبیر شده، نه همه اتاق‌های بینشان.
برای انتشار اینترنتی تصویرهای آرین، نظر/اجازه استفاده از طرح‌های تیمی را با آرین هماهنگ کنید. نقشه‌های AI را به‌عنوان پلان رسمی نمایش ندهید.
