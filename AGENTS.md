## Git attribution (project rule)

Never add AI co-author trailers to commits in this repository: no `Co-Authored-By: Claude …`, no `noreply@anthropic.com`, no other AI tool as co-author, and no "Generated with …" line in pull-request descriptions. Commits carry only the human author. Disclose AI assistance in `README.md` and the course documentation instead. For Claude Code, `.claude/settings.json` sets `attribution` to empty strings to enforce this.
